# Echo v0.2 Roadmap

v0.2 is an architecture and correctness release.

## Done

- Language semantics documented
- Typed AST
- Semantic analyzer
- Lexical scoping and closures
- Predictable `use mut` in nested blocks
- Echo error types and source locations
- Builtins removed from the lexer
- Regression tests and CI
- Version `0.2.0`

## Frozen

The v0.2 pipeline is frozen. v0.2.1 stress-tested it and did not require a pipeline, scope-model, AST, or runtime rewrite.

Coverage: [v0.2.1-coverage.md](v0.2.1-coverage.md). Remaining later work is v0.3 features, not architecture.

## Not in v0.2

- Modules and packages
- Classes / generics / macros
- Bytecode VM
- HTTP / database libraries
- LSP / formatter

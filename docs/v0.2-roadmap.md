# Echo v0.2 Roadmap

Historical. v0.2 was the architecture and correctness release. Current language is past 0.7.x — see `CHANGELOG.md` and the [capability matrix](/language-capability-matrix).

## Done (v0.2)

- Language semantics documented
- Typed AST
- Semantic analyzer
- Lexical scoping and closures
- Predictable `use mut` in nested blocks
- Echo error types and source locations
- Builtins removed from the lexer
- Regression tests and CI
- Version `0.2.0`

## Frozen

The v0.2 pipeline stayed frozen. v0.2.1 stress-tested it without a rewrite.
Coverage: [v0.2.1-coverage.md](v0.2.1-coverage.md). Modules landed in v0.3; host/stdlib in v0.4; later syntax and tooling in 0.5–0.7.

## Not in v0.2 (many later shipped)

At freeze time this list was out of scope. Do not read it as current status:

- Modules and packages → modules in v0.3 (still no package manager)
- Classes / generics / macros → still held
- Bytecode VM → still held
- HTTP / database libraries → still held
- LSP → still held; formatter / REPL / test runner shipped later

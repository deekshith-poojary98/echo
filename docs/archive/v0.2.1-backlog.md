# Echo v0.2.1 Backlog

> **Historical archive.** Not current language status. See [Roadmap](/project/roadmap).

Historical. Architecture was **frozen** for this slice.

v0.2.1 was semantic cleanup and regression only. Do not treat the “out of scope” list as today’s capability matrix — modules, REPL, first-class functions, and more shipped afterward. See `CHANGELOG.md` through 0.7.5.

If a stress test had proved the architecture wrong, the rule was: stop and reopen v0.2. That did not happen.

---

## P0 — semantic consistency

Resolved under the existing pipeline:

- [x] User-function keyword-argument validation (mixed, missing, unexpected, duplicate)
- [x] Builtin argument validation for required standalone calls
- [x] Python exception leaks found by the torture tests (`foreach`, `order`, `for` bounds, index assignment)
- [x] Error categories: argument / index / mutation / semantic

## P1 — semantic edge cases

Covered by combination tests:

- [x] closures + `use mut`
- [x] shadowing + mutation
- [x] nested blocks + nested functions
- [x] recursive closures
- [x] collection mutation of captured names
- [x] nested calls

At the time, returning a function from a function was a **later language decision**, not a v0.2.1 bug. First-class functions including lambdas shipped in **0.6.0**.

## P2 — test quality

`docs/archive/v0.2.1-coverage.md` traces each semantics section to tests.
Pressure tests live under `tests/semantics/` and `tests/runtime/`.

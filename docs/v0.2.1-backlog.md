# Echo v0.2.1 Backlog

Architecture is **frozen**.

Do not add modules, REPL, classes, HTTP, generics, IR, or a VM here.
If a stress test proves the architecture itself is wrong, stop and reopen v0.2.
Otherwise this release is semantic cleanup and regression only.

Known debt, isolated and deferred:

```text
Known debt
├── builtin arity
├── mixed keyword arguments
└── stale documentation
```

---

## P0 — semantic consistency

- User-function keyword-argument validation (mixed positional + keyword, missing names, duplicates)
- Builtin argument validation (`wait()`, optional vs required, standalone vs method form)
- Any remaining Python exception leakage
- Error-message consistency (wording, codes, locations)

## P1 — semantic edge cases

Stress combinations, not isolated features:

- closures + `use mut`
- shadowing + mutation
- nested blocks + nested functions
- recursive closures
- collection mutation of captured names
- nested calls
- function values, if the contract still claims them

The test that decides whether the runtime model hangs together:

```echo
fn makeCounter() {
    x: int = 0;

    fn increment() {
        use mut x;
        x += 1;
    }

    return increment;
}

counter = makeCounter();
counter();
counter();
```

Today Echo does not treat functions as assignable values. That is either a missing language rule in `docs/language-semantics.md` or a missing implementation. Resolve it in v0.2.1 without changing the pipeline.

## P2 — test quality

Every rule in `docs/language-semantics.md` gets an executable regression test.

Preferred layout when tests grow:

```text
tests/
├── semantics/
│   ├── scope/
│   ├── mutability/
│   ├── functions/
│   ├── types/
│   └── errors/
├── runtime/
│   ├── expressions/
│   ├── statements/
│   ├── collections/
│   └── builtins/
└── programs/
    └── integration/
```

Write tests from the semantics document, not from the interpreter internals.

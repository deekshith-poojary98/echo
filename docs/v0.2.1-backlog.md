# Echo v0.2.1 Backlog

Architecture is **frozen**.

Do not add modules, REPL, classes, HTTP, generics, IR, or a VM here.
If a stress test proves the architecture itself is wrong, stop and reopen v0.2.
Otherwise this release is semantic cleanup and regression only.

---

## P0 — semantic consistency

Resolved under the existing pipeline:

- [x] User-function keyword-argument validation (mixed, missing, unexpected, duplicate)
- [x] Builtin argument validation for required standalone calls
- [x] Python exception leaks found by the torture tests (`foreach`, `order`, `for` bounds, index assignment)
- [x] Error categories: argument / index / mutation / semantic

## P1 — semantic edge cases

Covered by combination tests:

- [x] closures + `use mut`
- [x] shadowing + mutation
- [x] nested blocks + nested functions
- [x] recursive closures
- [x] collection mutation of captured names
- [x] nested calls

Do **not** treat this as an implementation gap:

```echo
fn makeCounter() {
    x: int = 0;

    fn increment() {
        use mut x;
        x += 1;
    }

    return increment;
}

counter = makeCounter();
counter();
counter();
```

The contract already answers it. `docs/language-semantics.md` lists function as a runtime value type, then says:

> Functions are not first-class values in source syntax yet, except that
> `order(comparator)` may refer to a function by name.

So `return increment` / `counter = makeCounter()` is a **language decision for later**, not a v0.2.1 bug.

## P2 — test quality

`docs/v0.2.1-coverage.md` traces each semantics section to tests.
New pressure tests live next to the existing `tests/semantics/` and `tests/runtime/` layout.

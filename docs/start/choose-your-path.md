# Choose your path

Echo is a **programming language**. You write instructions, save them, and Echo runs them for you.

You do **not** need to know programming to start.

Pick one path. You can always try the other later.

## Path A — Try in the browser (no install)

Best if you want to see Echo work in the next minute.

1. Open the [Playground](/playground).
2. Wait until the status says **Ready** (Echo is loading in the browser).
3. Click **Run**.
4. Look at the **OUTPUT** panel on the right.

You should see:

```text
Hello, Echo!
```

Then change the word inside the quotes and click **Run** again.

**Next:** [Your first program](/learn/first-program)

---

## Path B — Install on your computer

Best if you want Echo files on your machine.

1. Follow [Install Echo](/getting-started/installation).
2. Create a file named `hello.echo`.
3. Run it with `elang hello.echo`.
4. See `Hello, Echo!` printed.

**Next after install:** [Your first program](/learn/first-program)
